`fetchCandidates` records traversal, never action completeness. `toEngineInput` is a trust boundary: every supplied proof requires a verified status, dated coverage, source and method; assertions are not independently checked for truth by code. Callers must obtain and assess independent evidence for every asset and calendar before supplying it. The test's evidence is expressly synthetic. This does not validate a production evidence process. Sessions are supplied by the caller; this module does not derive exchange calendars or completed-bar cutoffs.

For an owner-authorized private check only, explicitly configure `ALPACA_PRIVATE_VALIDATION=explicit`, `ALPACA_KEY_ID`, `ALPACA_SECRET_KEY`, `ALPACA_SYMBOLS`, `ALPACA_START`, `ALPACA_END`, and `ALPACA_FEED` in the process environment, then run `node --conditions=react-server --experimental-strip-types tests/alpaca-private.mjs`. The command does not load dotenv files and fails before requesting data if any setting is missing. It prints counts and conditional evidence only. Do not put secrets in shell history, command arguments, fixtures, or logs. This command has not been run with credentials, and cannot establish the missing evidence above.

## Server boundary and resource limits (2026-11-02)

The adapter imports Next.js `server-only`; `node tests/alpaca-boundary-negative.mjs` creates a disposable project with a client route, verifies that an isolated credential-free Next build rejects it for the server-only boundary, and removes the project. Standalone Node tests and the private script use `--conditions=react-server` to select the server export; that flag is for trusted server execution, not a browser bundle. An injected transport is trusted server-side code and receives credentials in request headers. Never inject untrusted code or log its arguments.

Successful response streams are read incrementally. Defaults are 2 MiB per response, 32 MiB aggregate, 16,384 chunks per response, 10,000 records per page, 250,000 bars and 25,000 actions per request. Configuration has explicit finite upper bounds and accepts lower limits. A limit violation cancels the stream and fails with `LIMIT`; headers are not relied upon. These budgets bound the adapter's retained stream bytes and parsed input size, not memory that an injected transport allocates before yielding a chunk. Custom transports must stream bounded chunks, avoid pre-buffering, honor aborts, and be trusted with secrets. Injected sleep implementations should honor their abort signal; the adapter also races caller cancellation so a noncooperative delay cannot trigger another request.
