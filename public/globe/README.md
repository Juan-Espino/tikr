# Globe assets

Source: Natural Earth 1:110m physical land, obtained from the same URL used by the supplied v0 component:
https://raw.githubusercontent.com/martynafford/natural-earth-geojson/refs/heads/master/110m/physical/ne_110m_land.json

Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/

`land.json` is the downloaded coastline data. `dots.json` and `fallback.svg` are derived locally with `node scripts/generate-globe.mjs`. The map is decorative, not market data or a statement about borders.
